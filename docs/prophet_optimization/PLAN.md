**PROPHET 双原型预测指标优化方案（2026-10-21）**


本文以当前源码、实际数据与检查点诊断为依据。区分已经验证的实现问题、结构上缺失的信息路径、尚需训练验证的改进假设。尚未修改生产模型、训练流程或历史成绩，也未启动新训练。优化对象是空间原型、时间原型及二者组合；不以追加外部模型模块作为方案。

**1. 先明确消融结果说明什么**

历史 seed=88 完整模型与关闭分支的结果中，关闭时间分支的 MAE 增幅：CQ 0.59%、HZ 0.39%、CHI-Taxi 0.40%、NYC-Taxi 1.72%；关闭空间分支分别约 3.37%、3.06%、7.29%、2.90%。因此优先研究时间分支的独立贡献有依据。

但是 `use_temporal=False` 同时去掉时间检索和时间 Query 网络；重新训练后其余路径可以补偿。它既不等于冻结权重删除时间检索，也不能证明时间原型没有作用。当前 `use_proto=False` 删除整个增强分支，亦不是保留其他网络的纯码本消融。

本次使用五个数据集 seed=42 的现有 checkpoint，严格加载当前模型；每个数据集取均匀分布的8个验证批次。重构前向与完整前向最大绝对误差不超过 9.54e-6（归一化输出）。未用测试指标挑选新模型。

| 数据集 | 空间分配熵/log(K) | 空间检索/Query变化幅度 | 空间分配改均匀：MAE变化 | 时间分配改均匀：MAE变化 |
|---|---:|---:|---:|---:|
| CQ | 0.9781 | 3.24% | +6.66% | +4.30% |
| HZ | 0.9918 | 1.60% | +0.83% | +6.66% |
| NYC-Taxi | 0.9828 | 3.13% | +4.32% | +19.53% |
| CHI-Taxi | 0.9848 | 1.09% | +0.50% | +3.30% |
| NYC-Bike | 0.9819 | 2.54% | +0.97% | +13.14% |

幅度使用去均值、经过输出投影后的 RMS；不是贡献百分比。均匀替换保留原型值表、Query和其余网络，但改变了冻结模型的中间分布；以上不是重训练消融，也不是整个验证集的成绩。

两类实验合起来提出待验证的解释：时间检索对已经训练好的模型有作用，但重训练时其他路径可能补偿其功能。优化目标应是让时间原型承担清楚、有效的预测任务，而不是仅强迫分配更尖锐或删掉旁路。

**2. 必须先修复的评估与输入问题：R0**

空间查询在 `models/PROPHET/spatial.py:93` 同时平均时间维和 batch 维。加载器按连续窗口组批，实际数据满足 `X[i+24,:,:,0] == y[i,:,:,0]`；五个数据集的训练、验证、测试起始批次均已验证。默认64样本的批次中，前40个样本的完整24步目标会出现在后续样本的输入历史内，并通过空间查询的batch均值参与前面样本预测。这里确认的是未来信息路径，不是量化其对成绩的收益。

训练后的实际检查点也有组批依赖：在选取的8个验证批次中，仅把每批第一个样本改为单独推理，其预测的平均绝对变化再对8批取平均，CQ/HZ/NYC-Taxi/CHI-Taxi/NYC-Bike分别约1.095/3.012/4.134/0.951/5.177（原始流量单位）。这是预测差异，不是MAE增量，也不是修复后重训练结果。

另外，按窗口索引划分使训练/验证、验证/测试边界的目标重叠23步。要按目标时间段分割，只保留完整目标区间落在所属分割内的样本；允许验证窗口使用预测时已经可见的训练末尾历史。当前24步、stride=1情形，可保留原验证和测试起点，分别移除训练末尾与验证末尾23个跨界窗口，保证目标不重叠；若按严格“首个验证预测起点之前才能完成训练”部署协议，还需让训练目标截止不晚于该预测起点，单独记录这一更严格约束。

最小模型修复：保留单样本历史 `h[b,n]`，与空间身份拼接形成 `q_s[b,n]`，分配改为 `(B,N,K_s)`，不再跨batch聚合。先保留其他所有模块和参数规模，不同时改变训练目标。

验收：同一个样本单独推理、与不同样本组批、改变batch大小及跨批重排后，eval预测在浮点容差内一致；分割目标时间集合无交集。必须从头训练，不能用旧checkpoint直接更改组批方式后所得成绩替代新基准。修复后指标若下降，应解释为去除不当信息与改变输入分布，不能据此撤销修复。未来的新旧比较全部以同协议R0为基线；要重做完整对比表，其他基线也必须统一数据协议重新训练。

**3. 时间原型：优先验证其独立预测作用，而非增加深度**

当前历史24步已被编码成一个完整窗口向量，不能说只看最后一个观测。真正的限制是：时间分配只在窗口级计算一次，条件为自身历史和最后历史时刻的日内/星期身份；不同预测步共用同一时间检索结果。原输出层仍有24个不同通道，因此不意味着24步预测相同，也不意味着模型理论上不能预测未来周期。

**T1：让时间原型承担未来步的模式修正。** 保留原模型预测、主干和所有Query路径，复用现有历史编码、时间嵌入、分配器和值表，计算：

```text
a_t(0) = softmax(f_t(h, e_last) / tau_t)
a_t(j) = softmax(f_t(h, e_future(j)) / tau_t)
r_t(j) = a_t(j) P_t
y_new(j) = y_R0(j) + eta * v^T [r_t(j) - r_t(0)]
```

`eta`零初始化、`v`非零初始化，初始预测与R0一致；额外参数为一个投影向量和一个系数，而不是换整个预测头。所有尺度保持在归一化输出空间。这一差分形式专门测试未来时刻引起的原型选择变化，而不是再加一个任意常量修正。对照中用当前时间Query投影的 `q_t(j)-q_t(0)` 替代检索差分，使用相同输出修正参数；若只有Query修正有效，说明收益来自日历条件，而不能归功于时间原型。

未来日历来自数据的真实有效采样日程，不使用未来流量。CQ/HZ只包含08:00–20:30的26个半小时槽，不能统一按 `(last_slot+j)%48` 推算；其他三个数据集为48槽全天。跨夜、跨星期必须单测。已知日历并不是新信息，T1是在现有信息上检验更直接的预测路径是否有效。

诊断与验收：按预测步及是否跨峰谷/跨日统计完整验证集误差；T1必须在多种子中改善相应时段，且整体MAE/RMSE不出现不接受的交换。若T1不优于同预算Query修正，放弃“时间原型特有收益”的解释，保留更简单者或不加入。

**T2：时间路由的空间条件。** 当前时间分配器没有显式节点、图或空间原型输入。相同历史及时间身份会给出同样时间分配，即使其空间身份不同；已在结构探针中验证。历史可能隐含节点差异，下游网络也可补偿，所以这只是路由层的缺项，不是整个模型没有时空交互。T2与组合模块C为同一项实验，不重复计数，见第5部分。

暂不把增加时间原型数、换更深分配器、历史形状/幅度分解或加熵损失列为必做项。只有在R0完整验证集上观察到同一时间原型内有稳定的分步残差结构，且训练样本足以支持拆分时，才做原型数量对照；不能仅因为去时间分支的消融损失小就堆容量。

**4. 空间原型：区分身份编码和当前空间状态**

当前空间分支使用图初始化的可学习节点身份，但没有样本内跨节点观测交互：历史编码、原型检索和1×1 MLP均逐节点运算。结构实验只改变其他节点历史流量100，目标节点预测变化严格为0。因此图嵌入提供的是静态信息，不能传递其他节点此次观测的变化。

**S1：通过现有空间原型组织当前观测。** 在R0单样本分配 `A[b,n,k]` 上，将同一样本中其他节点的历史编码汇聚为原型状态，再按目标节点分配读回：

```text
V[b,n] = W_v h[b,n]
U[b,k] = sum_n A[b,n,k] V[b,n]
M[b,k] = sum_n A[b,n,k]
u_minus_n[b,n,k] = (U[b,k] - A[b,n,k] V[b,n])
                  / (M[b,k] - A[b,n,k] + eps)
c_s[b,n] = sum_k A[b,n,k] u_minus_n[b,n,k]
r_s_new = r_s + eta_s W_o c_s
```

显式排除自身，便于证明这条新路径传入了其他节点信息。无有效其他节点质量时令该槽贡献为0，避免小分母放大。`eta_s`零初始化，保留身份原型检索、历史和Query通路。实现先计算U/M再减去自身，不构造N×N邻接；计算规模约为 `O(B N K_s D)`。必要时按节点分块读回控制显存。

这不是已经证明会提高精度。验证前先在训练集拟合小型残差预测探针，以自己的历史/身份为控制项，再加入其他节点经原型汇聚的历史，仅在验证集比较残差解释能力；不把残差相关本身当作因果证据。

关键对照：均匀权重的跨节点汇聚、打乱节点与空间分配对应关系、参数规模相近的纯节点内修正。若均匀汇聚与原型汇聚相同，收益属于其他节点输入，不能证明空间原型组织有优势；若无稳定收益，删除S1。

空间分配确实平滑，但目前不能据此认定塌缩。R0后记录逐样本熵、原型利用、分配对历史变化的敏感度，再验证固定温度0.5对比一个正值可学习温度；不同时调整原型数量，不把低熵作为优化目标，不强制各原型均匀使用。

**5. 两个原型的组合：从输出相加改为可检验的条件选择**

当前原型融合为 `H + W(r_s+r_t+q_s+q_t)`。不能断言相加没有非线性交互，因为后续MLP和独立子空间仍可表达交互。确定缺少的是：空间原型身份不参与时间原型的选择。

**C：空间原型条件化时间分配。**

```text
C_eff = C - row_mean(C) - col_mean(C) + mean(C)
a_t = softmax((f_t(h,e_time) + a_s C_eff) / tau_t)
```

16×8关联矩阵仅128个参数，双中心化去掉所有行相同而等价于额外时间logit偏置的分量，以及各行常数被softmax抵消的分量；有效自由度为15×7。C零初始化，初始严格还原原时间分配。必须在R0之后加入，避免将batch未来信息继续传给时间分支。

先单独比较R0与R0+C；再比较T1与T1+C，复用同一个C，不为每个未来步复制关联表。关联矩阵只做条件先验，历史和时间条件仍由原分配器决定。它可能因空间分配太平而近似常量，所以需要检验条件项的样本/节点方差，而非仅展示热图。

关键对照：C为零、全局logit偏置、打乱空间分配、直接空间身份条件化的参数预算相近对照。只有C在同预算下表现更好、打乱真实对应关系后收益消失，才支持“原型关系有效”；否则只能称加入空间条件有效。

**6. 原型贡献、组合收益必须拆开验证**

统一保留主干、空间/时间Query、融合输出投影；单独控制检索项，重新训练：

| 实验 | 保留的检索/机制 | 回答的问题 |
|---|---|---|
| Q | 不加r_s/r_t，保留两个Query | 额外Query本身能做多少 |
| Q+S | 只加空间检索 | 空间检索的独立作用 |
| Q+T | 只加时间检索 | 时间检索的独立作用 |
| R0=Q+S+T | 两个检索相加 | 两个检索是否互补 |
| R0+T1 | 未来步时间原型修正 | 时间原型是否改善未来模式变化 |
| R0+S1 | 原型组织其他节点状态 | 空间原型是否增加有效观测信息 |
| R0+C | 空间条件时间选择 | 条件组合是否优于原相加 |
| R0+T1+C | 时间修正与条件选择 | 组合是否增强时间原型作用 |
| R0+T1+S1+C | 仅合并已通过筛选的项 | 最终结构是否仍有增益 |

失活的Query/原型项、参数量、梯度实际是否更新均需记录，避免空注册参数冒充公平预算。Query-only不使用现有`use_proto=False`，因为后者含义不同。组合比两个单模块各自好，才支持实际组合收益；如要声称超加性，还需报告误差差分 `E_ST-E_S-E_T+E_Q` 及其不确定性，不能只展示Full最好。

**7. 训练与工程修正：与架构实验分开**

- 温度改用 `softplus(raw)+eps` 保证为正，并初始化为旧数值。当前检查点时间温度约0.31–0.38，未发现已经变负，故此项是稳定性约束而不是已证性能修复。
- `--dropout` 当前未传入PROPHET，MLP固定0.1。补齐参数映射后默认仍为0.1，先验证默认输出行为保持一致。
- 内部T维只是同一窗口编码的复制，1×1层最后只取第一个位置。可以独立去掉复制节约计算；eval等价已验证，但训练dropout随机数消费会改变，不能宣称逐步训练完全等价，更不能将其当作精度创新。
- 当前只用MAE训练和选checkpoint，验证虽计算RMSE/MAPE，history没有保存。补齐每轮验证全部指标、分预测步指标、路由统计和梯度范数；架构筛选阶段继续固定MAE目标，避免损失函数与架构同时改变。
- 学习率在20/40/50等轮各乘0.1。已有最优轮次集中在41/42/50附近，只能提出日程可能限制有效更新的假设。用相同总预算对比“原日程”和“仅首次降学习率后延后第二次下降”一项；若采用新日程，R0和候选必须同时重跑，不能只给新模型更好的训练条件。
- 五数据集实际目标非负、无NaN，当前训练MAE与评估MAE的mask在这些数据上相同；本次不把mask差异、浮点时间索引误差当作性能原因。
- MAE包含零值，MAPE仅计入满足阈值的非零目标。后续若MAPE仍落后，先按训练集确定的流量分组统计验证误差及其贡献。不要直接用相对误差损失提高MAPE而忽略MAE/RMSE交换；损失调整作为独立实验，报告完整Pareto结果。

**8. 快速可执行的实验顺序与停止条件**

第一步：完成R0、数据协议及记录修复，保存版本标记和split清单，通过组批不变性、时间边界、输入可见性检查。五数据集各跑seed42的R0，形成真实完整验证基准。

第二步：先用CQ和NYC-Taxi、seed42筛选，二者分别有时间消融增益小、时间路由冻结干预明显且MAPE待改进的现象。优先T1、C、T1+C，随后S1；每项都单独相对R0比较。完成4个单种子变体×2数据集，共8次候选训练，不先展开原型数/温度/层数的大网格。S1不因结构缺项就自动成为最终模型。

第三步：保留至多两个候选，在CQ/NYC-Taxi补seed13、88，R0也补齐这两个种子，共至多12次训练。同时补必要的Query、均匀汇聚、打乱条件等解释性对照。若某项在两个筛选数据集都没有超过R0的稳定验证收益，停止推广；如果只是增加参数或引入日历的普通对照更好，不把它包装成原型收益。

第四步：最多一个主候选推广至剩余三个数据集，使用13/42/88三种子，补齐配对R0。所有模型在同一干净验证划分上使用同一选模规则，固定方案后再评估测试。当前已反复查看过旧测试成绩，今后严格限定新增选择使用验证集；条件允许时预留新的时间外推区间作最终确认。

每次记录MAE、RMSE、MAPE的逐种子差值、均值、样本标准差及训练/推理成本。优先采用验证MAE、RMSE均改善且MAPE不退步的候选；出现指标交换就完整列出，不事后更换主指标。小幅收益用时间块配对bootstrap辅助评估，不能把重叠滑窗的每个元素当独立样本；仅3个seed不足以作很强的统计显著性结论。门槛应由干净R0的实际波动确定，不预先保证提升百分比。

改动落点：`spatial.py`负责R0/S1，`temporal.py`负责正值温度和未来时间路由，`prototype.py`负责C和检索控制，`model.py`负责T1输出修正与日历接口，`dataset.py`及预处理元数据负责目标时间划分，`engine.py/config.py/checkpoint.py`负责日志、实验开关与版本。新增配置建议显式记录`architecture_version`、`split_version`、`spatial_context_mode`、`temporal_horizon_mode`、`prototype_relation_mode`、两个检索开关；避免继续复用含义会变化的`use_proto`标签。

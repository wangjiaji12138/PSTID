# 为什么当前线性编码对照与原型版效果接近

> 本文记录的是修改前的含旁路结构。当前模型已改为 `encoded_only_v1`，本文指标不代表新结构，需重新训练评估。

本次检查的是已经训练完成的吉林、上海模型，seed=88，两组各自的训练和结构配置除 `use_proto` / 编码器类型外一致。没有修改模型结构或重新训练。原始诊断数据见 [jl.json](jl.json)、[sh.json](sh.json)，工具为 [diagnose_prototypes.py](../../experiments/diagnose_prototypes.py)。

结论：没有证据支持“整个原型模块严格等价于线性映射”。更具体的原因是：原型只是完整表示之外的一条附加路径；空间原型已学成变化幅度较小、平滑且容易替代的修正，而对照保留了较强的 Query 路径，包括时间分支的非线性 MLP。时间原型本身仍有明显非线性和实际作用。

## 1. 代码中的真实比较对象

令空间输入为 `x_s`，时间输入为 `x_t`；`H` 为主干拼接的历史、日内时间、星期、节点和图嵌入。

原型版计算：

```text
q_s = Linear(x_s)
r_s = softmax(normalize(q_s) normalize(P_s)^T / tau_s) P_s

q_t = Linear(GELU(Linear(x_t)))
r_t = softmax(Linear(GELU(Linear(x_t))) / tau_t) P_t

H' = H + Linear(q_s + q_t + r_s + r_t)
预测 = 回归层(残差 MLP(H'))
```

线性对照只将 `r_s` 和 `r_t` 换成两个仿射映射，仍保留所有其他路径。时间分支中的 Query 投影依然包含 GELU，主干也依然包含 ReLU。因此，将两者称为“原型网络对纯线性网络”并不准确。

空间对照中 `q_s + Linear2(Linear1(x_s))` 可以精确合并为一个仿射映射。时间对照中则为 `GELU-MLP(x_t) + Affine(x_t)`，仍具有非线性表达能力。

原型输出 `r` 虽然位于原型凸包中，但 `q_s`、`q_t` 和 `H` 不受这一约束。最终表示没有被强制压缩到少量原型内。当前训练对 PROPHET 只使用预测损失，没有要求原型必须成为聚类中心、必须去噪或必须形成明确分工的额外目标。正交初始化也不等于训练过程中持续保持正交。

## 2. 已训练参数显示空间分配接近均匀、小幅变化

| 诊断量 | 吉林 | 上海 |
| --- | ---: | ---: |
| 空间分配熵 / log(16)，均匀分配为 1 | 0.98726 | 0.98627 |
| 空间最大分配权重均值，均匀值为 0.0625 | 0.09950 | 0.09992 |
| 空间原型变化幅度 / Query 变化幅度，经输出投影后 | 2.33% | 2.55% |
| 时间原型变化幅度 / Query 变化幅度，经输出投影后 | 9.67% | 12.63% |
| 空间原型两两余弦相似度均值 | -0.00317 | 0.00808 |
| 时间原型两两余弦相似度均值 | 0.03970 | 0.04069 |

变化幅度指在完整测试输入上去均值后的 RMS，并应用 `proto_out_proj.weight`，不含其偏置。空间统计按节点-批次计算，时间统计按样本-节点计算。幅度比较本身不是贡献百分比；后面的冻结权重干预才直接测量预测敏感性。

原型间余弦相似度不高，不能将现象简单归因为“所有原型向量塌成同一个向量”。更明显的是空间分配很平滑，变化部分远小于旁边的 Query 路径。

对 logits `l`，Softmax 在均匀分配附近的一阶展开为：

```text
softmax(l) ≈ 1/K + (l - mean(l))/K
r ≈ mean(P) + ((l - mean(l))/K) P
```

该一阶近似对空间原型输出的测试 R² 分别为 **0.9662 / 0.9552**。这说明空间 Softmax 在这些已训练模型上主要工作在近似线性的区域。注意它是相对于 logits 的近似；logits 内仍有 Query 归一化，不能据此声称对原始输入严格线性。

进一步直接从原始分支输入 `x_s` 拟合仿射映射，空间原型输出测试 R² 为 **0.8696 / 0.7772**。输出并非完全线性，但剩余误差落在一条幅度很小的路径上。

## 3. 冻结权重后，直接替换原型输出会怎样

仿射替代器只用训练集均匀选取的 16 个原始批次拟合，采用带截距的 float64 SVD 最小二乘。以下 MAE 全部在完整测试集计算，网络其他权重不变，也不微调。

| 推理方式 | 吉林 MAE | 上海 MAE |
| --- | ---: | ---: |
| 原型 checkpoint 原始前向 | 0.549720 | 1.007163 |
| 仅把空间原型输出替换为拟合的仿射映射 | 0.550350 | 1.009050 |
| 仅把时间原型输出替换为拟合的仿射映射 | 0.559348 | 1.025464 |
| 空间、时间原型输出都替换为拟合的仿射映射 | 0.559706 | 1.026417 |
| 两个原型输出都置零，保留 Query | 0.716797 | 1.252535 |
| 两个 Query 输出都置零，保留原型输出 | 1.383173 | 2.959873 |
| 原型输出换成训练集均值，空间按节点、时间用全局均值 | 0.574923 | 1.066743 |
| 独立训练完成的 Linear-MLP checkpoint | 0.547270 | 1.004852 |

这几行区分了三件事：

1. **空间原型输出很容易替代。** 即使完全不重新训练，换成仿射映射的 MAE 增幅也只有约 0.11% / 0.19%。
2. **原型输出实际被使用。** 直接置零会明显损害性能，不能解释为网络彻底忽略原型；不过冻结权重的置零会引入分布变化，不能等同于从头训练时的必要性证明。
3. **时间原型并未完全线性化。** 其仿射替代测试 R² 只有 0.6251 / 0.6905，替换会导致约 1.75% / 1.82% 的 MAE 增幅。独立训练的对照可以重新调整 Query 和主干，这与冻结权重直接替换是不同的问题。

因此，现有证据支持的解释是：空间原型学到了容易被仿射层替代的小修正；时间原型虽有非线性作用，但现有对照也有非线性 Query 和主干，可在重新训练时承担类似预测功能。后者是结构和实验支持的解释，不是已经逐参数证明的吸收关系。

## 4. 效果接近不等于预测函数相同

原型版与独立训练的线性对照，逐预测值的平均绝对差分别为 **0.12498 / 0.24242**，预测相关系数为 **0.99820 / 0.99811**。它们总体趋势接近，但输出并不相同。

参数量也不完全匹配：吉林为 **97,809 / 102,536**（原型 / 线性），上海为 **99,953 / 104,680**。隐藏宽度改为 `proto_emb_dim` 后，对照并不是受原型数量限制的低维分配网络。

## 5. 验证边界与复现

- 仅分析 seed=88 的两个数据集，不能推广为所有种子和数据集的性质。
- 诊断采用 CPU float32 推理；相对保存的 CUDA 测试 MAE，吉林差约 0.000025、上海差约 0.000043。所有干预都与同一 CPU 基准比较。
- 诊断重构前向与模型原始前向进行了张量一致性检查；吉林还通过现有 `training.engine.evaluate` 独立复核完整测试集，MAE 与诊断基准一致。
- 测试集没有参与拟合仿射替代器或均值。
- 本次没有修改训练、模型或现有 checkpoint，只添加诊断工具与报告。

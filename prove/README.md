# PROPHET 原型分配优势的数学分析

本目录针对当前 `use_proto=1` 与 `use_proto=0`（`Linear → Softmax → Linear`，中间维度为原型数量）的对照，不针对早期删除整个分支或单 Linear 的版本。

完整证明见 [prototype_advantage.md](prototype_advantage.md)。参考草稿在仓库中实际名为 [TOPROVE.md](../TOPROVE.md)；其中不能成立或不能用于本次对照的推导，逐项记录在 [TOPROVE_audit.md](TOPROVE_audit.md)。

本文严格证明了以下结论，并明确区分分支性质与完整网络的预测效果：

| 结论 | 严格性与范围 |
| --- | --- |
| 两种分支都具有共享字典、凸组合及至多 `K−1` 维的输出仿射包 | 固定参数、仅增强特征；不能用作两者之间的低秩优势证据 |
| 空间余弦分配对 Query 的正比例缩放不变 | Query 范数处于归一化的非截断区间；不等于完整预测不变 |
| 在方向决定目标、幅值为干扰的构造分布上，空间原型分支具有严格误差优势 | 给出四点分布、有限参数的严格差距，以及有界参数类的正风险下界 |
| 时间 GELU 分配器的函数类包含线性分配器 | 任意原型数量；给出逐参数构造 |
| 时间分支可具有严格的表达能力优势 | `K=2` 的四点交互任务：原型分支 MSE/MAE 为零，对照分别至少为 `1/16`、`1/8` |
| 表达优势何时转化为训练后风险优势 | 给出统一收敛误差及优化误差必须满足的充分条件 |
| 已知低维仿射结构何时降低估计误差 | 独立、固定设计的辅助定理；不能直接套用到本次两个同为 `K` 维分配的分支 |

这些证明支持“在明确条件下为何可能更好”，不支持“所有数据集、所有训练结果都必然更好”。当前完整网络均保留主干，仅 `use_proto=1` 保留 Query 残差；这些路径能绕过增强分支；真实预测优势需要同版本、多种子实验及机制验证。

数值核验使用实际 `SpatialCodebook` / `TemporalBasis`，不修改模型、训练数据或检查点：

```bash
python prove/verify_math.py > prove/verification.json
```

[verify_math.py](verify_math.py) 检查函数重参数化恒等式、尺度不变性及其 Jacobian、GELU 交互构造、参数计数，以及已知仿射空间的精确风险公式。[verification.json](verification.json) 保存执行结果与被核验代码的 SHA-256。数值核验用于发现实现或代数错误，正文中的解析证明才是定理依据。

# TOPROVE.md 的数学复核与修正

参考文件实际为 [TOPROVE.md](../TOPROVE.md)，并非 `TO_PROVE.md`。本文件保留原稿不动，将影响严谨性及当前适用性的关键问题集中说明。修正后的完整推导见 [prototype_advantage.md](prototype_advantage.md)。

## 1. 比较对象已经改变

当前 `use_proto=0` 是 `Linear → Softmax → Linear`，中间维度为 `K`。其第二个 Linear 的偏置可以吸收到各个输出向量中，所以它本身也是 `K` 个可学习向量的凸组合。

因此，原稿中“原型用 K 个共享向量，对照使用 d 维无约束独立表示”的比较，不能直接解释当前实验。两边的固定字典输出仿射维数均至多为 `min(d,K−1)`；还都保留了不受此凸包限制的 Query 和主干。

## 2. 线性代数与投影部分

| 原稿位置或说法 | 必须修正的内容 |
| --- | --- |
| `col(W) ⊆ col(P)` 就使 `Wx+b` 落在该子空间 | 还需要 `b ∈ col(P)`。共享输出子空间也不意味着两种函数类相同，尤其 Softmax 系数受到单纯形约束。 |
| 独热输入推导中 `W=Pᵀ` | 若采用列向量且 `W ∈ R^{d×V}`、`P ∈ R^{d×K}`，在 `V=K` 的查表对应下应是 `W=P`。原稿混用了行/列记法。 |
| 仿射子空间投影是线性的 | 一般是仿射映射；仅对经过原点的线性子空间，正交投影才是线性映射。 |
| 活跃约束固定就能唯一写出最优分配系数 | 投影点唯一，但若字典仿射相关，分配系数可以不唯一。系数的仿射表达需要相应秩与唯一性条件；投影点在多面体的适当区域上可分段仿射。 |
| 把投影型分配结论用于当前 Softmax 分配 | 代码没有求解 `min_{α∈Δ} ||z−Pα||²`，所以投影的最优性和风险性质不会自动成立。 |
| `P` 把系数空间等距嵌入到输出空间 | 只有 `PᵀP=I` 等明确条件下才是等距。正交初始化不保证训练中始终正交。 |

固定分配后对字典作平方损失最小二乘，确实具有正规方程。但当前代码是带残差和非线性主干的端到端 MAE 训练，没有执行这一字典回归子问题。

## 3. 原稿统计定理 1 的缺口

1. **估计字典与真实字典被混用。** `α̂` 是用 `P̂` 拟合的，证明却直接将其写成真实 `P*` 设计矩阵下的 OLS 解。即使 `P̂` 与 `P*` 很接近，字典扰动也会影响系数、可识别性和误差相关项；这些项需要显式控制。
2. **单纯形的等式约束始终存在。** 在相对内部只能说非负性约束局部不活跃，`1ᵀα=1` 不会消失。应在 `K−1` 维切空间上分析，不能直接当成 K 维无约束 OLS。
3. **可逆性没有假设。** A2 不保证 `P*` 满列秩，原稿使用的 `(P*ᵀP*)⁻¹` 可能不存在。处理冗余原型应基于实际子空间维数或伪逆。
4. **A3 是强假设，不是 A2 的推论。** 低秩凸组合不等同于可分离硬聚类；没有锚点、分离性或可识别性条件，不能由 K-means/硬 EM 直推出字典矩阵的估计速率。即使只考虑原型置换，也需定义对齐后的误差。
5. **概率余项不能直接变成期望余项。** `o_p(n^{-1/2})` 不单独推出平方误差中的 `o(n^{-1})`；还需要矩或一致可积性控制。
6. **同数据学习字典引入依赖。** 固定设计 OLS 协方差公式不能不加处理地用于由同一噪声选择的随机字典或子空间。
7. **严格比较条件需保留全部项。** 即使接受原稿风险界，也需要显式满足 `2K/λ + 2C₁dK/V + 余项 < d/Λ`。`V ≫ d` 是定性说法，不能直接作为有限样本严格不等式。

其中原稿的无约束 OLS 风险公式，在固定、满秩设计和零均值同方差噪声下是正确的。完整证明正文的定理 11、推论 12 用固定已知仿射空间或凸包给出不含上述漏洞的版本，并显式加入结构失配偏差。

## 4. 原稿泛化定理 2 的缺口

- 若覆盖数上界为 `log N(ε) ≤ D log(C/ε)`，Dudley 积分中的维度通常以 `sqrt(D)` 形式进入，不能据此直接推出原稿中只含 `sqrt(log D)` 的复杂度界。
- 需要明确定义参数范数约束、度量、输入范围、输出范围以及标量损失类。对向量预测函数类不能不经损失复合或收缩论证，直接使用标量损失的 Rademacher 界。
- 无界参数的线性函数类不具有原稿所写的有限复杂度上界；“损失有界”也不能替代对所使用函数类的完整定义。
- 即使分别证明了 `complexity_P ≤ U_P` 和 `complexity_L ≤ U_L`，`U_P < U_L` 也不推出真实复杂度严格有序。
- 即使两个泛化风险上界严格有序，也不推出实际风险严格有序。证明严格风险优势，需要一边的上界低于另一边有效的下界，或直接分析风险差。
- 当前训练数据包含时空依赖；独立样本结论需要独立性假设或针对依赖数据的替代证明。

因此本目录不沿用原稿中未经正确推导的 Rademacher 数值表达式。正文定理 10 改用明确的统一偏差假设，并证明它在何种条件下足以转化为风险优势。

## 5. 梯度与优化叙述

当前使用有限 logits 的 Softmax，每个分配权重都严格为正，不是“只有被选中原型更新”的硬路由。

例如时间分支在固定分配 `α`、上游梯度为 `g=∂ℓ/∂z` 时，有 `∂ℓ/∂P = gαᵀ`，所有列一般都接收梯度。空间分支还因键值共享而存在分配路径上的额外梯度。不能把固定硬分配的分块更新结论用于当前软分配实现。

最小范数插值、尖锐极小值、泛化优劣都需要具体损失、优化算法、初始化和数据条件。它们不能仅从“一个参数叫 prototype、另一个叫 Linear”推导出来。

## 6. 应保留的研究方向

原稿提出的“共享结构可形成统计归纳偏置”值得保留，但本次对照的两边都已共享字典。更合适的研究对象是：

- 空间归一化究竟滤掉了干扰还是有用幅值；
- 空间键值共享的约束是否符合数据结构；
- 时间非线性分配是否提供了实际需要的交互能力；
- 这些收益是否超过估计误差与优化代价，并真正影响最终预测。

正文分别提供精确性质、严格构造和条件风险定理。对于真实数据上的因果解释，仍需同版本对照和机制实验，不能由本文件替代。
